# Death Trench 2D（原版）

2D 俯视角射击游戏（搜打撤 / 生存 / 更多模式）。

## 运行
```bash
cd death-trench-2d
npm start          # 启动 http://localhost:8080
```
- 普通版：`/`
- 开发版（带编辑器）：`/dev`

## 目录结构
- `index.html` 普通版页面
- `index-dev.html` 开发版页面
- `js/` 游戏逻辑（utils / anti-cheat / save / coord / game）
- `css/` 样式
- `assets/` 图片资源
- `server.js` 零依赖静态服务器
- `api.js` 后端接口
- `tools/` 辅助工具页
