# 死亡战壕 - 更新报告

> 更新时间：2026-07-24  
> 版本：1.0.x  
> 面向玩家：反馈作弊与存档安全问题的各位战士

---

## 本次重点更新

### 1. 反插件 / 反作弊拦截增强

为响应玩家反馈的作弊插件问题，游戏新增并增强了客户端反作弊模块：

- **禁用开发者工具入口**
  - 拦截常见开发者工具快捷键
  - 检测 DevTools 打开行为
  - 禁用浏览器右键菜单

- **插件 / 脚本注入检测**
  - 扫描 DOM 中异常残留元素
  - 检测异常全局变量与可疑脚本
  - 检测隐藏 iframe 与异常注入

- **运行环境监测**
  - 检测 `console` 是否被插件重写过
  - 检测 `window` 上是否被挂载多个可疑全局属性
  - 检测游戏是否被嵌套在 iframe 中

- **本地存档保护**
  - 包装 `localStorage`，异常删除存档数据时记录
  - 触发异常后保护当前合法数据

> ⚠️ 说明：网页端反作弊无法做到 100% 绝对阻止，但可显著提高作弊门槛，并对异常行为进行记录与提示。

---

### 2. JSON 存档验证码机制

为防止存档文件被外部修改后重新导入：

- 导出 JSON 存档时，会自动附加验证码
- 验证码基于存档内容、时间戳与内部校验因子生成
- 导入存档时若验证码不匹配，将拒绝加载并提示“存档可能已被篡改”
- 具体算法不公开，以避免被针对性绕过

---

### 3. 设置面板修复

修复了部分浏览器中设置面板触发的报错：

- `settings is not defined` → 已将 `settings` 显式挂载到 `window`
- `hideSettings is not defined` → 确认已挂载到 `window` 并清理缓存
- CSS/JS 文件已添加 `?v=3` 缓存清除参数，避免旧版本缓存导致的问题

---

### 9. 数据完整性保护

- `savePlayerData()` 与 `loadPlayerData()` 增加同步签名校验
- `SaveManager` 的自动存档与手动存档槽位也加入了签名
- 对金币、击杀、得分等关键数值的异常增长进行检测与提示

---

### 10. 新反馈问题修复

#### 10.1 弹药购买 UI 同步

- 购买弹药后即时同步到 `playerData.ammo` 与 `deathTrench_playerData`
- 调用 `renderAmmoBackpack()` 与 `updateAmmoBackpackDisplay()` 刷新弹药背包显示

#### 10.2 近战武器禁止配件

- `toggleMod()` 中新增近战武器检测，无法为匕首、砍刀等装备任何配件
- 改装商店中对近战武器选中时，配件项显示禁用样式并提示

#### 10.3 地图美术优化

- 重新调整 8 张预设地图配色，使沙漠、丛林、雪地、火山等主题更鲜明
- 为每个地块增加边框与层次阴影，提升立体感
- 地面随机生成岩石、草丛、碎片等装饰细节

#### 10.4 新手教程改为界面导览

- 教程不再只是文字翻页，而是自动带你进入每个界面
- 每步高亮目标区域（底部导航、战备中心、仓库、黑市、改装处等）
- 提示框跟随高亮元素，支持上一步/下一步/跳过

#### 10.5 更新公告系统

- 玩家进入游戏时自动弹出最新更新公告
- 公告内容同步发送到信箱，方便随时查看
- 勾选“不再提示此版本”后，该版本公告不再弹窗（信箱中仍可查看）
- 旧版本公告邮件会自动清理

#### 10.6 反作弊误报修复

- 修复了正常游玩时频繁弹出“检测到异常行为”的问题
- 降低 DevTools 尺寸检测、脚本注入检测、全局变量检测的敏感度
- 反作弊脚本不再因文件名含 `cheat` 而自我告警
- 触发严重响应需要更高的可疑分数且至少两种不同原因
- 新增 `[AntiCheat debug]` 日志，便于排查具体触发点

#### 10.7 右键射击与武器切换修复

- 右键射击改为 `mousedown` 事件触发，响应更稳定
- 移除右键对“自动连发”开关的干扰，右键始终单发
- 出战武器限制为最多 4 把，避免超出 HUD 武器栏
- 武器栏按钮根据实际出战武器动态生成，切枪显示更准确

## 自迭代10代更新（2026-07-26-v2）

### 1. 敌人 AI 与行为优化

- A* 寻路启发函数加入 tie-breaking，减少不必要的节点探索，降低卡顿
- 敌人会根据玩家当前武器类型调整战术：
  - 玩家持刀时，敌人保持距离并横向移动
  - 玩家持霰弹枪时，敌人远距离迂回，避免贴脸
  - 玩家持狙击枪时，敌人蛇皮走位靠近
- 普通敌人低血量时概率进入逃跑状态，持续 2~4 秒后恢复
- 每帧最多 1 个敌人重算路径，避免多敌人同时寻路导致 CPU 峰值

### 2. 地图美术与细节升级

- 8 张预设地图配色进一步优化
- 障碍、建筑、掩体、水面新增专属细节：
  - 障碍：裂缝、岩石阴影
  - 建筑：窗户与窗框
  - 掩体：沙袋
  - 水面：动态波纹
- 地块层次阴影与边框增强，立体感更明显

### 3. 视觉特效与战斗反馈

- 敌人受击时添加白色闪烁反馈
- 击杀敌人时产生爆发式爆炸特效，Boss 击杀效果更华丽
- 枪口闪光、子弹拖尾、屏幕震动、受击红屏等已有反馈保持稳定

### 4. 新增任务

- 丛林猎杀：在丛林地图消灭 25 名敌人，奖励 700 金币
- Boss 猎手：消灭 1 个 Boss，奖励 1000 金币

### 5. 反作弊与存档安全

- 扩展作弊工具全局变量检测库，覆盖更多常见作弊社区与工具
- 保持多因素判定策略，避免正常游玩误报
- 存档验证码机制继续保护导入路径，具体算法不公开

### 6. 性能优化

- 地图渲染热路径内联 `getTile`，减少每帧函数调用与字符串拼接
- 对象池（子弹、爆炸、掉落物）继续控制内存分配

### 7. UI/UX 修复

- 新手教程切换面板后延迟一帧重新定位高亮框与提示框
- `showPersonalInfo()` 统一调用 `ensureLobbyPanelsVisible()`，避免个人界面与主界面层级不一致

## 已知限制

1. 客户端反作弊只能提高门槛，无法替代服务端权威校验
2. 验证码机制保护的是“导入”路径，直接修改浏览器本地存储仍属于客户端可控范围
3. 部分浏览器扩展（如广告拦截、翻译插件）可能误触发检测，如遇到请反馈
