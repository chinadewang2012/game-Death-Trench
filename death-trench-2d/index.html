📖 新手教程

🎮 欢迎来到死亡战壕

这是一款2D俯视角射击游戏，你将扮演死亡战壕特遣队战士，在各种战场中消灭敌人！

🏃 移动控制

使用 WASD 或方向键控制角色移动。游戏支持流畅的8方向移动，让你在战场上灵活穿梭。

🔫 射击系统

使用鼠标瞄准。右键点击发射子弹，按空格键开启/关闭连发模式（连发模式下再次按右键也可停止射击）。

🎯 武器切换

按数字键 1、2、3 切换武器。手枪适合近距离战斗，步枪是全能选择，狙击枪一击必杀！

⚡ 战术道具

击杀敌人会掉落金币、医疗包、弹药箱等道具。靠近自动拾取，提升战斗力！

🎖️ 准备战斗！

现在你已经掌握了基本操作，准备好迎接挑战了吗？祝你好运，战士！
